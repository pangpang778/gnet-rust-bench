# gnet-rust-bench

Rust rewrite benchmark of [panjf2000/gnet](https://github.com/panjf2000/gnet) (Go, Apache-2.0).

- `BRIEF.md` — the rewrite brief (scope, acceptance criteria)
- `gnet-go/` — the original Go source snapshot (dev branch) for reference

This repo hosts the results of an AI-agent benchmark: the same brief was sent to independent bot platforms; their outputs land on separate branches/PRs.
